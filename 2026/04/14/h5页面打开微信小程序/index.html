h5页面打开微信小程序

发表于2026-04-14|更新于2026-08-17|功能
|浏览量:

功能：通过微信扫码打开h5页面，点击页面上的按钮，跳转到微信小程序。

方案1：使用开放标签wx-open-launch-weapp，将h5页面中的按钮点击事件绑定到微信小程序的跳转链接。
方案2：使用wx.miniProgram，要求页面配置到小程序内，才可以调用成功

方案1

首先登录微信公众平台进入“服务号设置”的“功能设置”里填写“JS接口安全域名”，之后在页面中引入开放标签的js-sdk文件。

注意：服务号必须是非个人认证，否则无法使用开放标签

<script src="https://res.wx.qq.com/open/js/jweixin-1.6.0.js"></script>

通过config接口注入权限验证配置并申请所需开放标签，config中的 signature 签名必须由后端服务生成。

const _url = location.href.split('#')[0];
const params = new URLSearchParams({
  url: _url, // 当前url，主要用以验证域名是否合法
  _t: new Date().getTime() // 时间戳
});
fetch(`${接口url}?${params.toString()}`).then(res => res.json()).then(response => {
  wx.config({
    debug: true, // 开启调试模式,调用的所有api的返回值会在客户端alert出来，若要查看传入的参数，可以在pc端打开，参数信息会通过log打出，仅在pc端时才会打印
    appId: response.appId, // 必填，服务号的唯一标识
    timestamp: response.timestamp, // 必填，生成签名的时间戳
    nonceStr: response.nonceStr, // 必填，生成签名的随机串
    signature: response.signature,// 必填，签名
    jsApiList: ['previewImage'], // 必填，需要使用的JS接口列表
    openTagList: ['wx-open-launch-weapp'] // 可选，需要使用的开放标签列表，例如['wx-open-launch-app']
  })
  wx.ready(function() {
    // 开放标签初始化完成后，调用wx-open-launch-weapp标签
    const btn = document.getElementById('launch-btn');
    if (btn) {
      btn.addEventListener("ready", function() {
        console.log("开放标签初始化成功")
      })
    }
  })
  wx.error(function(res) {
    // 开放标签初始化失败，打印错误信息到控制台，方便调试
    console.log(res)
  })
});

开放标签初始化完成后，即可使用wx-open-launch-weapp标签。

<body>
  <div class="page">
    <p>点击按钮打开小程序</p>
    <wx-open-launch-weapp
      id="launch-btn"
      appid="服务号appid"
      path="需要跳转的小程序页面"
    >
        <!-- 注意：此标签内为独立隔离沙盒，和上下文完全隔离，使用图片或其他资源必须使用链接形式引用，不支持本地路径引用 -->
      <script type="text/javascript">
        <style>
          .jump-btn {
            width: 100px;
            height: 45px;
            line-height: 45px;
            text-align: center;
            font-size: 16px;
            margin: 0 auto;
            border: none;
            border-radius: 4px;
            background: #07c160;
            color: #ffffff;
          }
        </style>
        <div>
          <button class="jump-btn">打开小程序</button>
        </div>
      </script>
    </wx-open-launch-weapp>
  </div>
</body>
<style>
.page {
  height: 100%;
  width: 100%;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
}
</style>

一定要注意 wx.config 中相关配置

  1. appId 必须是正式服务号的唯一标识
  2. signature 必须是正式服务号appid生成的签名
  3. jsApiList 必填，必须写一个
  4. openTagList 必须包含 wx-open-launch-weapp
