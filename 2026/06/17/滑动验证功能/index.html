滑动验证功能

发表于2026-06-17|更新于2026-08-17|功能
|浏览量:

最近公司更新了新的验证组件，之前是文字点选验证，现在要全面替换为滑动验证。滑动验证主要是为了检验是否人为操作，避免通过工具批量调用一些接口，例如获取手机验证码、预约等场景

公司提供的组件是js原生方法，里面包含了 js、css及图标icon相关资源，公司项目是vue项目，首先在入口页面引入相关资源，资源放置到public目录下。

<script src="./captcha/js/sliceCaptcha.js"></script>
<link rel="stylesheet" href="./captcha/css/sliceCaptcha.css"></script>

注意：在另外一个项目中，引入通过控制台发现获取不到相关资源，经过排查发现，打包配置中有个配置项需要修改

// assetsPublicPath 决定资源引用前缀‌：打包生成的 index.html 中，由构建工具自动插入的 <script>、<link> 标签的 src 或 href 属性，会以此配置值作为前缀。
// 例如设为 './'，则资源路径变为 ./static/js/app.js；设为 '/' 则为 /static/js/app.js。
// assetsPublicPath: '/social/fee/card' 原有配置
assetsPublicPath: process.env.NODE_ENV === 'production' ? '/social/fee/card' : ''

整个验证码交互流程

<template>
  <!-- 滑动验证码挂载dom -->
  <div v-if="sliceCaptchaDialog" class="captcha-overlay" style="z-index: 2003;"></div>
  <div v-if="sliceCaptchaDialog" class="captcha-dialog" style="width: 370px;z-index: 2004;">
    <div id="sliceCaptcha"></div>
  </div>
</template>
<script>
  export default {
    data() {
      clientId: null, // 秘钥
      sessionId: null, // 秘钥绑定sessionId，接口传递sessionId，通过其查找对应clientId，进行加密解密
      sliceCaptchaDialog: false,
      sliceCaptcha: null
    },
    methods: {
      // 步骤一：获取秘钥，用于图片及滑动轨迹数据加密 
      getClientId() {
        this.axios.post('接口地址', '入参', {
          headers: {
            'Content-Type': 'application/json;charset=utf-8'
          }
        }).then(res => {
          if (res.code === '200') {
            this.clientId = res.data.clientId;
            this.sessionId = res.data.sessionId;
            this.sliceCaptcha && this.sliceCaptcha = null;
            this.sliceCaptchaDialog = true;
            this.$nextTick(() => {
              this.createSliceCaptcha('sliceCaptcha');
            })
          }
        })
      },
      createSliceCaptcha(divId) {
        this.sliceCaptcha = new SliceCaptcha(divId, {
          // 相关配置项，包括背景宽高、秘钥等信息
          clientId: this.clientId,
          // 初始化实例会自动调用，获取背景图及滑块图片
          requestData: (param, successCallback, errorCallback, capchaObject) => {
            let requestData = JSON.stringify({
              cpatchaType: 'slice_data',
              ...param, // 背景图宽高及滑块宽高
              sessionId: this.sessionId
            })
            this.axios.post('接口地址', requestData, {
              headers: {
                'Content-Type': 'application/json;charset=utf-8'
              }
            }).then(res => {
              if (res.code === '200') {
                successCallback(res.data) // 会进行解密base64，展示滑动验证组件
              }
            })
          },
          sendData: (resData) => {
            const requestData = JSON.stringify({
              captchaType: 'slice_check',
              data: resData,
              sessionId: this.sessionId
            })
            this.axios.post('接口地址', requestData， {
              headers: {
                'Content-Type': 'application/json;charset=utf-8'
              }
            }).then(res => {
              if (res.data === "success") {
                this.sliceCaptchaDialog = false; // 验证成功
              } else {
                this.getClientId()
              }
            })
          }
        })
      }
    }
  }
</script>
